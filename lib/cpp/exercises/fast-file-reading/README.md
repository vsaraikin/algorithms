# Fast File Reading — "How can I read a file, fast!"

Упражнение на производительность I/O и парсинга в C++.

Видео-разбор: https://www.youtube.com/watch?v=Et1owjLHpS4

## Задача

Дан файл `gas_stations.csv` на **10 миллионов строк** в формате `Location;Temperature`.

- ~10 000 уникальных станций (locations).
- Температуры в диапазоне `-99.9 … 99.9`, всегда с одним знаком после запятой (`22.0`).
- Нужно прочитать файл **быстро** и посчитать сводную статистику по каждой станции: `min`, `max`, `average` (через `sum` и `count`).
- Форматирование вывода не важно.

Суть: **как прочитать файл максимально быстро.**

## Подходы

### Version 1 — наивный (baseline) — ~1520 ms

`std::ifstream` + `std::getline` + `std::stof`, ключи `std::string`.

Узкие места:
- `getline` копирует каждую строку в `std::string`;
- `std::stof` медленный (локаль, обработка ошибок, парсинг общего вида);
- `records[station]` конструирует `std::string`-ключ на каждый lookup даже когда станция уже есть;
- буферизованное чтение через stdio-слой.

### Version 2 — `mmap` + zero-copy парсинг — значительно быстрее

Идеи:

1. **`mmap`** файла в память вместо `read`/`getline`. Файл виден как один непрерывный `char*`, копирования в буферы нет. `madvise(MADV_SEQUENTIAL)` подсказывает ядру агрессивно префетчить страницы (читаем последовательно).
2. **`std::string_view`** на участки замапленной памяти — парсим **без аллокаций и копий**. Границы полей ищем через `std::ranges::find` по `;` и `\n`.
3. **`std::from_chars`** вместо `std::stof` — без локали, без исключений, парсит прямо из диапазона `[begin, end)`. Самый быстрый способ распарсить число.
4. **Гетерогенный lookup** в `unordered_map` (C++20): кастомный хешер с `using is_transparent = void;` позволяет искать по `std::string_view`, **не** создавая временный `std::string`-ключ на каждый запрос (`records.find(string_view)`).
5. **RAII-обёртка `MappedFile`** — `open`/`mmap` в конструкторе, `munmap`/`close` в деструкторе, `std::span<const char> Data()` наружу.

## Ключевые техники (что показать на собесе)

| Техника | Зачем |
|---------|-------|
| `mmap` + `madvise(MADV_SEQUENTIAL)` | убрать копирование и дать ядру префетчить |
| `std::string_view` | парсинг без аллокаций |
| `std::from_chars` | быстрый парсинг чисел без локали/исключений |
| `is_transparent` хешер | lookup по `string_view` без создания `string`-ключа |
| RAII для дескриптора/маппинга | безопасность при исключениях |

## Замечания по сборке

Код использует **POSIX** (`mmap`, `open`, `madvise`, `munmap`) и возможности **C++23** (`std::println`).
→ собирать на Linux/macOS с `-std=c++23`; под Windows потребуется `CreateFileMapping`/`MapViewOfFile`.

`main.cpp` — реконструкция из видео; отдельные строки (например `fstat`) восстановлены по смыслу и помечены комментариями.
